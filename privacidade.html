Sobre os dados deste convite

Este é um convite digital de aniversário. Para funcionar direito e para que quem criou o convite possa acompanhar o evento, algumas informações são registradas:

  • Confirmação de presença: se você preencher o formulário de RSVP, seu nome, se vai comparecer e uma mensagem opcional ficam salvos para quem organiza a festa ver.
  • Abertura do convite: quando você abre o convite, registramos apenas que o link foi acessado (sem coletar localização, IP ou dados do seu dispositivo), para que quem fez o convite saiba quantas pessoas o visualizaram.
  • Se você clicar no link "criado por" no rodapé para pedir seu próprio convite, isso também é registrado — é assim que a pessoa que criou este convite sabe que você tem interesse em conversar.

Esses dados não são vendidos, compartilhados com terceiros, nem usados para nada além do que está descrito acima. Se quiser que alguma informação sua seja removida, é só pedir diretamente a quem te enviou este convite ou a quem o criou.
